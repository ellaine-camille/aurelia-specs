# INBOX

**Purpose:** collect team observations and contributions that have not yet been verified or assigned a permanent document.

**Confidence note:** template-only note; no entries have been investigated. The code wins (see 16).

## Instructions

A rough entry beats no entry. Give evidence and explain what breaks if the point is ignored.

```markdown
### <summary>
- **Type / Author / Date:**
- **What:**
- **Why:** what improves, or what breaks without it.
- **Evidence:** files, commits, PRs, or the incident.
```
